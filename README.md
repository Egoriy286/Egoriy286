## 📚 Research Areas

My main research direction is the development and investigation of computational methods for partial differential equations, with a focus on multiscale modeling, inverse problems, and scientific machine learning.

### Multiscale FEM
Generalized Multiscale Finite Element Methods (GMsFEM) for wave scattering and heterogeneous media.

### Inverse Problems
Numerical recovery of unknown coefficients in parabolic and related mathematical-physics problems.

### Scientific Machine Learning
PINNs, FBPINNs, and neural operator approaches for PDEs, including the connection between data-driven operators and classical FEM solvers.

## 🚀 Selected Projects

### [`inverse-parabolic-coefficient-recovery`](https://github.com/Egoriy286/inverse-parabolic-coefficient-recovery)
Numerical recovery of an unknown coefficient in a two-dimensional parabolic equation using FEM and FEniCSx/DOLFINx.

**Focus:** inverse problems · FEM · regularization · noisy data · numerical experiments

### [`multiscale-fem-scattering`](https://github.com/Egoriy286/multiscale-fem-scattering)
Implementation and investigation of a generalized multiscale finite element approach for scattering problems in heterogeneous media.

**Focus:** GMsFEM · Helmholtz equation · heterogeneous coefficients · multiscale modeling

### [`FBPINN-scattering`](https://github.com/Egoriy286/FBPINN-scattering)
Exploration of Finite Basis Physics-Informed Neural Networks for scattering problems.

**Focus:** FBPINNs · PDEs · scientific machine learning · wave scattering

### [`PINN-eikonal`](https://github.com/Egoriy286/PINN-eikonal)
Numerical solution of the Eikonal equation using Physics-Informed Neural Networks.

**Focus:** PINNs · nonlinear PDEs · neural approximation

### [`transformer-from-scratch-jax`](https://github.com/Egoriy286/transformer-from-scratch-jax)
Educational and experimental implementation of Transformer architecture using JAX.

**Focus:** attention mechanisms · neural architectures · JAX
